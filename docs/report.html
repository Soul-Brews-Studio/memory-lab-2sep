The finding: where the data lives decides the latency

local wrangler dev
11 ms
Bangkok caller, server-side
33–51 ms
Bangkok caller, round trip
191 ms
claude.ai (IAD), server-side
745 ms

The Worker runs in the caller’s colo; D1 is single-region and was placed in APAC on first use. Each request makes 3–4 sequential D1 queries — bearer lookup, client label, the tool itself; the ledger write is async. From BKK that is 33–51 ms; from IAD 468–761 ms. Same code, about 15× slower across the Pacific.

Follow-ups: D1 read replication (Sessions API), or cache the bearer per isolate so a call costs one query, not four.
